# Papeletas digitales SST — Demostración interactiva

Esta versión pública está preparada para alojarse como sitio estático en **GitHub Pages**. No contiene logotipos, nombres de empresas ni conexiones empresariales.

## Alcance de la demostración

- Registrar hallazgos positivos y negativos; para negativos, actos o condiciones inseguras con nivel de riesgo.
- Adjuntar una fotografía ficticia y dibujar una firma **ficticia**.
- Generar una papeleta imprimible o guardarla como PDF desde el navegador.
- Exportar registros a CSV y JSON; descargar Excel XLSX cuando la biblioteca ExcelJS esté disponible desde cdnjs.
- Crear, borrar y restablecer registros de muestra con nombres y códigos ficticios.
- Los registros solo se guardan en el almacenamiento local del navegador. No existe un servidor ni se sincronizan datos.
- Clave ilustrativa para desbloqueo: `0000` (sin seguridad real).

**No ingreses datos reales de trabajadores, DNI, firmas auténticas ni fotos de personas o instalaciones.** La demostración es un portafolio técnico y no está diseñada para uso operacional ni almacenamiento de información sensible.

## Publicar con GitHub Pages

1. Inicia sesión en GitHub y crea un repositorio **público**, por ejemplo `papeletas-sst-demo`.
2. Carga los archivos `index.html` y `.nojekyll` en la **raíz** de la rama `main` (también puedes subir `README.md`). **No subas versiones anteriores de la herramienta.**
3. Ve a **Settings > Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**; selecciona la rama `main` y la carpeta `/(root)`. Guarda.
5. Una vez publicado, tu URL tendrá normalmente esta forma: `https://TU_USUARIO.github.io/papeletas-sst-demo/`.
6. Abre el enlace en móvil y escritorio, comprueba que crea un registro ficticio y luego compártelo en LinkedIn.

*La publicación online todavía requiere realizar los pasos en tu cuenta de GitHub.*
